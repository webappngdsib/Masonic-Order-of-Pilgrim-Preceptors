# The Masonic Order of Pilgrim Preceptors · Region Hellas

Website for the founding of Region Hellas and its four new Conclaves.

Menu:
- **Invitation**: bilingual (Greek / English) personal invitation to founding membership.
- **Banners**: the official banners of the Region and of the four Conclaves (Athens, Piraeus, Corfu, Thessaloniki).
- **Calendar**: the joint Masonic Weekend dates for 2027 (confirmed) and 2028 (provisional), each with an add-to-calendar button.
- **Official Website**: link to https://pilgrimpreceptors.com/

Files:
- `index.html`: the site (menu sections: `#invitation`, `#banners`, `#calendar`).
- `assets/invitation/`: invitation pages (Greek, English).
- `assets/banners/`: banner images.
- Published via GitHub Pages by `.github/workflows/pages.yml`.
